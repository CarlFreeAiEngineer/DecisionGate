# Evaluation v2

Frozen synthetic evaluation set authored on 2026-09-17 before model selection or evaluation on this set. This file records the dataset at the moment of creation.

- Records: 80, all `split=test`; 40 yes and 40 no.
- Structure: 20 groups with two different questions about the same content (40 records), plus 40 independent contents (40 records); 60 content groups total.
- Coverage: refund, cancellation and appointment intent; coding and billing; duplicate reports; numeric criteria; negation; quoted instructions; ordinary eligibility, permissions and events.
- Schema: matched to the first record of `data/plain-questions.jsonl`; `criteria` is null or an object with `yes` and `no` strings. Every record includes a rationale.
- Provenance and review status: `synthetic_unreviewed`; licensed CC0-1.0.
- SHA-256 of `evaluation-v2.jsonl`: `ffda37e4ea80042a0a78c5be266c836c1ff3b6f13bffebe20c07553e0d1fb528`.

## Authoring and independence

Only the first existing dataset record was consulted to determine the schema. No other prior dataset records, model predictions, or prior model results were inspected. Examples were individually authored, not expanded through paraphrase templates. Labels follow information supplied within each example, without requiring hidden world facts. No model inference or model comparison was performed during authoring.

This set was generated by the same kind of assistant used in this project and is not a human-independent test. Synthetic labels have not been independently reviewed. The paired design and balanced labels also differ from a naturally sampled workload; report this limitation with results.

## Use

Keep this version frozen. Select prompts, training data, thresholds and models using other data before evaluating here. Do not use these records, rationales or fresh-test predictions to guide selection. If errors are later discovered, document them and create a new version instead of silently changing this file. Count paired records as related observations when interpreting uncertainty.
