What you are looking at

That is the whole thing: one function, two strings, one boolean. Your code can also call isYesP for the probability instead of a boolean, chooseP and choose to rank several options, and pass { criteria: { yes, no } } to spell out what counts; print writes to the box above. They are the same calls, with the same weights and the same answers, as the Python, Java, C#, C, Rust, and Node.js interfaces in the repository. See EXAMPLE_USAGE.md for every language.

To put this in your own page, copy the web/ folder from a release into your site's assets and import { isYes } from './web/index.js'. That is all. Hosting notes cover headers and content security policy.
